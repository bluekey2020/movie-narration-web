## 6. 技术决策快速参考

| 决策项 | MVP 选择 | 理由 |
|--------|---------|------|
| 工作流引擎 | Celery（非 Temporal） | MVP 阶段流程简单，Temporal 运维成本过高 |
| 视频理解 | 关键词匹配（非 CLIP/Marengo） | MVP 先用预置场景时间戳，AI 匹配 Phase 2 再入 |
| TTS 引擎 | narrator-ai API + Edge TTS fallback | 最快接通，CosyVoice2 自部署延后 |
| 视频合成 | FFmpeg（非 Remotion） | 批量效率优先，Remotion 用于预览 |
| 文件存储 | 本地文件系统（非 S3） | 开发阶段简化，上线前切 MinIO |
| 模型路由 | 仅 DeepSeek | 当前成本最优，多模型 fallback 后续加入 |

## 8. 风险 & 应对

| 风险 | 概率 | 应对 |
|------|------|------|
| DeepSeek API 不稳定 | 中 | 预置 Claude/OpenAI fallback prompt |
| FFmpeg 渲染复杂度过高 | 中 | 先用最简单的 concat 拼接出 MVP，后续迭代 |
| 前端开发速度瓶颈 | 高 | Sprint 1 只做核心路径，所有"锦上添花"的 UI 移到 Sprint 2 |
| narrator-ai API 不可靠 | 中 | Edge TTS 作为 fallback，配音质量暂时降级 |
| 数据扩充耗时 | 中 | 优先从 TMDB API 批量抓取，写脚本自动化 |
